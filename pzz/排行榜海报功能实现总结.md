# 排行榜海报功能实现总结

## 实现内容

已成功在 pzz 应用中添加排行榜海报导出功能，满足以下需求：

### ✅ 核心需求
1. **模板基础**：使用 `21 - 副本.html` 作为设计模板
2. **头像显示**：使用 `png` 目录下的图片（文件名：主播ID.png）
3. **公司名称**：可配置，默认"星嗨艺创"（已从"星嗨传媒"修改）
4. **活动标题**：可配置，默认"月度PK挑战赛排名"
5. **ID隐藏**：不显示主播ID，只显示排名
6. **等级显示**：显示等级而非音浪数值
7. **双图导出**：自动分为两张图片，每张单列显示

## 功能特点

### 1. 数据处理
- 按总音浪降序排序
- 自动分组（前半部分和后半部分）
- 前三名特殊展示（领奖台样式）
- 其余主播列表展示

### 2. 样式设计
- 金色主题，高端大气
- 渐变背景和光效
- 前三名显示奖牌图标
- 等级标签彩色显示

### 3. 头像处理
- 优先使用本地 png 目录图片
- 支持多个路径查找
- 无图片时显示占位图

### 4. 导出流程
1. 用户点击 FAB 菜单"导出排行榜"
2. 显示确认对话框
3. 生成 HTML 内容
4. WebView 渲染
5. 截图保存为 PNG
6. 自动调用分享功能

## 技术要点

### 1. WebView 渲染
- 在主线程创建 WebView
- 等待页面加载完成
- 延迟1秒确保渲染完成
- 使用 Canvas 截图

### 2. 协程处理
- 使用 `suspendCancellableCoroutine` 包装异步操作
- 支持取消操作
- 自动清理 WebView 资源

### 3. 文件分享
- 使用 FileProvider 安全分享
- 支持多图片分享
- 自动打开系统分享界面

## 使用流程

1. **准备头像**：将主播头像放入 `png` 目录
2. **配置设置**：在设置中修改公司名称和活动标题（可选）
3. **筛选数据**：选择日期、性别等筛选条件
4. **导出海报**：点击 FAB → 导出排行榜 → 确认
5. **分享图片**：选择分享方式（微信、QQ等）

## 注意事项

1. WebView 需要在主线程创建和操作
2. 渲染需要时间，导出过程中避免操作
3. 头像文件需提前准备好
4. 确保有文件读写权限
