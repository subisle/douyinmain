# 总音浪覆盖功能说明

## 功能概述

新增了从主播榜 CSV 文件覆盖本地数据库中指定日期总音浪的功能。该功能用于修正总音浪数据，确保与官方主播榜数据一致。

## 使用场景

当发现某一天的总音浪数据与官方主播榜不一致时，可以使用此功能直接从主播榜 CSV 文件覆盖本地数据库中的总音浪值。

## 使用方法

1. 准备主播榜 CSV 文件（如：主播榜 (66).csv）
2. 在 app 主界面点击右下角的 FAB 按钮（+号）
3. 选择"覆盖总音浪"选项
4. 选择要覆盖的目标日期
5. 选择主播榜 CSV 文件
6. 等待处理完成，查看结果提示

## CSV 文件格式要求

CSV 文件必须包含以下列：
- **主播ID** 或 **抖音号**：主播的唯一标识
- **音浪** 或 **声浪**：总音浪数值

示例格式：
```csv
排名,主播ID,抖音号,火山号,主播名,音浪,运营经纪人,招募经纪人
1,4469972183296288,91596939392,91596939392,狼兴🎹🎤,1002596音浪,星海传媒,星海传媒
2,4290762920961667,47901846924,47901846924,狼俊🎹🎤,819586音浪,星海传媒,星海传媒
```

## 功能特点

### 1. ID 前缀匹配
- 使用主播ID的前10位进行匹配
- 兼容不同长度的主播ID
- 提高匹配准确率

### 2. 本地和远程同步
- 自动更新本地数据库
- 同步更新远程数据库（如果启用）
- 保证数据一致性

### 3. 详细的结果反馈
覆盖完成后会显示：
- CSV 数据总量
- 匹配到的主播数量
- 本地更新成功数量
- 远程更新成功数量
- 未找到的记录数量
- 失败的记录数量

### 4. 安全性保障
- 只覆盖总音浪字段，不影响其他数据
- 使用参数化查询，防止 SQL 注入
- 完整的错误处理和日志记录

## 技术实现

### 核心文件

1. **TotalSoundOverwriteUtils.kt**
   - 位置：`pzz/app/src/main/java/com/example/myapplication/utils/`
   - 功能：解析 CSV 文件，执行覆盖操作

2. **RemoteDatabaseManagerV2.kt**
   - 新增方法：`updateTotalSoundWave()`
   - 功能：更新远程数据库中的总音浪

3. **SoundDataDao.kt**
   - 已有方法：`updateTotalSoundWaveByIdPrefix()`
   - 功能：根据 ID 前缀更新本地数据库

4. **SoundDataViewModel.kt**
   - 新增方法：`overwriteTotalSoundWave()`
   - 功能：协调覆盖流程

5. **MainActivity.kt**
   - 新增处理方法：`handleOverwriteTotalSound()`
   - 新增文件选择器：`overwriteTotalSoundCsvPicker`

6. **FABMenu.kt**
   - 新增按钮："覆盖总音浪"

### 数据流程

```
CSV 文件
  ↓
解析 CSV（TotalSoundOverwriteUtils）
  ↓
提取主播ID和总音浪
  ↓
本地数据库更新（SoundDataDao）
  ↓
远程数据库同步（RemoteDatabaseManagerV2）
  ↓
清除缓存并刷新界面
```

## 与其他功能的区别

### 覆盖总音浪 vs 更新总音浪

| 功能 | 覆盖总音浪 | 更新总音浪 |
|------|-----------|-----------|
| 数据源 | 主播榜 CSV | 日音浪 CSV |
| 更新方式 | 直接覆盖 | 累加计算 |
| 使用场景 | 修正错误数据 | 日常数据更新 |
| 影响字段 | 仅总音浪 | 总音浪和日音浪 |

### 覆盖总音浪 vs 更新日音浪

| 功能 | 覆盖总音浪 | 更新日音浪 |
|------|-----------|-----------|
| 数据源 | 主播榜 CSV | 日音浪 CSV |
| 更新字段 | total_sound_wave | sound_wave |
| 计算逻辑 | 无需计算 | 无需计算 |
| 使用场景 | 修正总音浪 | 修正日音浪 |

## 注意事项

1. **数据备份**：覆盖操作会直接修改数据库，建议操作前备份数据

2. **日期选择**：确保选择正确的目标日期，覆盖操作不可撤销

3. **CSV 格式**：确保 CSV 文件格式正确，包含必要的列

4. **网络连接**：如果启用了远程数据库同步，需要确保网络连接正常

5. **权限要求**：需要文件读取权限才能选择 CSV 文件

## 错误处理

### 常见错误及解决方案

1. **"CSV文件为空或格式不正确"**
   - 检查 CSV 文件是否包含数据
   - 确认文件包含"主播ID"和"音浪"列

2. **"未找到匹配的记录"**
   - CSV 中的主播ID在数据库中不存在
   - 检查主播名单是否已同步

3. **"远程更新失败"**
   - 检查网络连接
   - 查看日志获取详细错误信息

4. **"数据库连接失败"**
   - 检查远程数据库配置
   - 确认数据库服务是否正常
