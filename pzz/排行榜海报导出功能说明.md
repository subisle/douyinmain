# 排行榜海报导出功能说明

## 功能概述

新增了排行榜海报导出功能，可以将主播排行榜数据导出为精美的海报图片，方便分享和展示。

## 主要特性

### 1. 海报样式
- 基于 `21 - 副本.html` 模板设计
- 金色主题，高端大气
- 前三名特殊展示（领奖台样式）
- 其余主播列表展示

### 2. 数据显示
- **排名**：显示主播排名（不显示ID）
- **头像**：使用 `png` 目录下的图片（文件名为主播ID.png）
- **等级**：显示主播等级（而非音浪数值）
- **自动分页**：数据自动分为两张图片，每张单列显示

### 3. 可配置项
在设置界面中可以修改：
- **公司名称**：默认为"星嗨艺创"（原"星嗨传媒"）
- **活动标题**：默认为"月度PK挑战赛排名"

## 使用方法

### 1. 准备头像图片
将主播头像图片放入 `png` 目录，文件命名格式：`主播ID.png`

例如：
```
png/
  ├── 808691.png
  ├── 973217.png
  └── 731762.png
```

### 2. 配置海报设置
1. 点击右上角设置按钮
2. 找到"海报设置"部分
3. 修改公司名称和活动标题（可选）
4. 点击"保存"

### 3. 导出海报
1. 在主界面筛选需要导出的数据（日期、性别等）
2. 点击右下角的 FAB 按钮（+号）
3. 选择"导出排行榜"
4. 确认导出
5. 系统会自动生成两张图片并弹出分享界面

## 技术实现

### 核心文件
- `RankingPosterExportUtils.kt`：海报导出工具类
- `RankingPosterExportDialog.kt`：导出对话框
- `PreferencesManager.kt`：设置管理（新增海报设置）
- `SettingsScreen.kt`：设置界面（新增海报设置项）
- `FABMenu.kt`：FAB菜单（新增导出选项）
- `MainActivity.kt`：主界面集成

### 导出流程
1. 获取当前筛选的数据
2. 按总音浪降序排序
3. 分成两组（每组单列）
4. 使用 WebView 渲染 HTML 模板
5. 截图生成 PNG 图片
6. 保存到缓存目录
7. 调用系统分享功能

### 数据处理
- 排序：按总音浪降序
- 等级计算：使用 GradeManager 计算等级
- 头像加载：优先使用本地图片，无图片时使用占位图
- 昵称显示：使用 GenderUtils 获取显示名称

## 注意事项

1. **头像文件**：确保 png 目录下有对应的头像文件，否则会显示占位图
2. **WebView 渲染**：需要等待 WebView 渲染完成（约1秒），导出过程中请勿操作
3. **文件权限**：需要文件读写权限（已在 AndroidManifest.xml 中配置）
4. **分享功能**：使用 FileProvider 分享图片，确保 file_paths.xml 配置正确
