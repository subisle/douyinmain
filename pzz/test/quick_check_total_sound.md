## 快速检查清单

### 1. 查看Logcat日志
搜索关键字：`TotalSoundUpdateUtils`

**必须看到的日志**:
```
✅ CSV解析完成，共解析 X 条有效数据 (X > 0)
✅ 本地更新完成: 成功=X, 插入=X, 失败=0
✅ 验证: 该日期共有 X 条记录
✅ 验证记录: ID=..., 名称=..., 总音浪=XXX (总音浪 > 0)
```

**如果看到**:
```
❌ 共解析 0 条有效数据
   → CSV文件格式问题或音浪值都是0

❌ 本地更新完成: 成功=0, 插入=0, 失败=X
   → 数据库插入失败，查看错误日志

⚠️ 未找到主播信息，使用ID前缀创建
   → 本地数据库中没有该主播的历史记录
```

### 2. 检查CSV文件
打开CSV文件，确认：
- [ ] 第一行是表头
- [ ] 包含"ID"列和"音浪"列
- [ ] 音浪列格式：`838323音浪` 或 `83.8万音浪`
- [ ] ID列是完整的ID（至少8位）

### 3. 检查app显示
更新后：
- [ ] 切换到更新的日期
- [ ] 查看主播列表
- [ ] 检查"总浪"字段是否显示正确的值
- [ ] 如果显示0，尝试切换日期再切换回来

### 4. 导出数据库检查（可选）
```bash
# 导出数据库
adb pull /data/data/com.example.myapplication/databases/sound_data.db

# 检查数据
sqlite3 sound_data.db "SELECT COUNT(*) FROM streamer_data WHERE record_date = '2025-01-19' AND total_sound_wave > 0;"
```

## 常见问题快速解决

### 问题: CSV解析为0条
**解决**: 
1. 检查CSV文件编码（必须是UTF-8）
2. 确认表头包含"ID"和"音浪"
3. 确认音浪列不是空的

### 问题: 插入失败
**解决**:
1. 查看详细错误日志
2. 检查数据库权限
3. 尝试重启app

### 问题: 显示为0
**解决**:
1. 查看日志中的"解析音浪"值
2. 确认CSV中音浪格式正确
3. 导出数据库检查实际值

### 问题: 远程数据库没有数据
**解决**:
1. 检查网络连接
2. 检查数据库配置
3. 查看远程更新日志
