# 时长考勤页面按钮修复说明

## 问题描述
时长考勤页面点击顶部的"导出"、"分析"、"设置"等按钮没有反应。

## 问题原因
在 `DurationDataScreen.kt` 中，ModernHeader 的回调函数被设置为空或注释掉了：
- `onPhoneClick` - 直接写死了电话拨号逻辑
- `onShareClick` - 注释为"时长页面不需要分享功能"
- `onSettingsClick` - 注释为"打开设置"

## 修复方案

### 1. 修改 DurationDataScreen.kt
添加必要的回调参数：
```kotlin
@Composable
fun DurationDataScreen(
    data: List<DurationData>,
    statistics: DurationStatistics,
    selectedDateRange: Pair<String, String>,
    onBack: () -> Unit,
    onImport: () -> Unit,
    onSelectDateRange: () -> Unit,
    onExport: () -> Unit,           // 新增：导出回调
    onPhoneClick: () -> Unit,       // 新增：电话回调
    onSettingsClick: () -> Unit     // 新增：设置回调
)
```

将这些回调传递给 ModernHeader：
```kotlin
ModernHeader(
    selectedDate = "${selectedDateRange.first} ~ ${selectedDateRange.second}",
    totalSound = formatDurationForHeader(totalDurationSeconds),
    liveCount = "${filteredStatistics.activeCount} / ${filteredStatistics.totalCount}",
    isDurationMode = true,
    selectedGender = selectedGender,
    onGenderChange = { selectedGender = it },
    onDateClick = onSelectDateRange,
    onPhoneClick = onPhoneClick,      // 使用传入的回调
    onShareClick = onExport,          // 导出功能
    onSettingsClick = onSettingsClick // 使用传入的回调
)
```

### 2. 修改 MainActivity.kt 中的 DurationScreenWrapper
传递实际的回调实现：
```kotlin
com.example.myapplication.ui.screens.DurationDataScreen(
    data = state.data,
    statistics = state.statistics,
    selectedDateRange = selectedDateRange,
    onBack = onBack,
    onImport = { csvFilePicker.launch("*/*") },
    onSelectDateRange = { showDateRangePicker = true },
    onExport = { showExportDialog = true },  // 打开导出对话框
    onPhoneClick = {
        val phoneIntent = Intent(Intent.ACTION_DIAL)
        phoneIntent.data = Uri.parse("tel:13354463148")
        context.startActivity(phoneIntent)
    },
    onSettingsClick = {
        // 返回主界面并打开设置
        onBack()
    }
)
```

## 功能说明

### 电话按钮（左上角第一个图标）
- 点击后拨打电话：13354463148
- 会打开系统拨号界面

### 分享/导出按钮（左上角第二个图标）
- 点击后打开导出对话框
- 可以选择性别筛选（全部/男/女）
- 导出为PNG图片格式
- 支持按月份导出时长考勤数据

### 设置按钮（左上角第三个图标）
- 点击后返回主界面
- 可以通过底部导航栏进入设置页面
- 在设置页面可以删除时长数据
