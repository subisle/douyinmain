## 常见问题

### Q1: 编译失败

**A**: 确保已安装JDK 11或更高版本，并且Android SDK配置正确。

```bash
# 检查Java版本
java -version

# 清理并重新构建
./gradlew clean
./gradlew assembleDebug
```

### Q2: 安装失败

**A**: 检查设备是否已连接，并启用USB调试。

```bash
# 检查设备连接
adb devices

# 如果有多个设备，指定设备
adb -s <device_id> install -r app/build/outputs/apk/debug/app-debug.apk
```

### Q3: 推送仍然失败

**A**: 检查以下几点：

1. **网络连接**：确保设备能访问远程数据库（your_mysql_host:3310）
2. **数据库权限**：确认用户名密码正确
3. **数据格式**：检查CSV文件格式是否正确
4. **日志详情**：查看完整的错误日志

```bash
# 查看完整日志
adb logcat > logcat.txt
# 然后在logcat.txt中搜索错误信息
```

### Q4: 数据不完整

**A**: 运行验证脚本检查：

```bash
python verify_push_fix.py 2026-01-18
```

如果发现数据不完整：
1. 检查CSV文件是否包含所有56个主播
2. 检查是否有重复的streamer_id
3. 查看推送日志，找出失败的记录

## 技术细节

### 修复前后对比

**修复前**：
- 流位置错误导致包类型判断错误
- affected_rows始终为0
- 实际数据已插入但应用认为失败

**修复后**：
- 正确读取整个包到字节数组
- 从数组中解析包类型和affected_rows
- 准确返回插入结果

### 关键代码变更

```kotlin
// 修复前（错误）
val firstByte = input!!.readByte().toInt() and 0xFF  // ❌ 流位置错误

// 修复后（正确）
val packetData = ByteArray(length)
input!!.readFully(packetData)
val firstByte = packetData[0].toInt() and 0xFF  // ✅ 从数组读取
```
