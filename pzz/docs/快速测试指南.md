## 常见问题排查

### Q1: 连接超时

**症状**：
```
E/SimpleMySQLClient: 连接失败: java.net.SocketTimeoutException
```

**解决**：
1. 检查网络连接（WiFi/移动数据）
2. 确认数据库地址正确：your_mysql_host:3310
3. 尝试在PC上测试连接：
   ```cmd
   python pzz\test\test_db_connection.py
   ```

### Q2: 认证失败

**症状**：
```
E/SimpleMySQLClient: 认证失败: Access denied for user
```

**解决**：
1. 检查AppConfig.kt中的配置：
   - DB_USER = "your_username"
   - DB_PASSWORD = "your_password"
   - DB_NAME = "your_database"
2. 确认数据库账号权限

### Q3: 表不存在

**症状**：
```
E/SimpleMySQLClient: MySQL错误: 1146 - Table 'your_database.streamer_data' doesn't exist
```

**解决**：
运行Python脚本创建表：
```cmd
python pzz\test\test_db_connection.py
# 按提示输入 y 创建表结构
```

### Q4: 推送部分失败

**症状**：
```
D/RemoteDatabaseManagerV2: 成功: 43 条, 失败: 13 条
```

**解决**：
1. 查看详细错误日志
2. 检查失败的记录ID
3. 可能是数据格式问题（特殊字符、NULL值等）
4. 检查网络稳定性

### Q5: affected_rows仍然是0

**症状**：
```
D/SimpleMySQLClient: 更新成功: affected_rows=0, insert_id=0
```

**这说明修复没有生效！**

**解决**：
1. 确认SimpleMySQLClient.kt已更新
2. 重新编译应用：
   ```cmd
   cd pzz
   gradlew clean
   gradlew assembleDebug
   ```
3. 重新安装：
   ```cmd
   adb install -r app\build\outputs\apk\debug\app-debug.apk
   ```
4. 完全卸载后重新安装
