# Android App 导入功能说明

## 三个导入功能的区别

### 1. 导入日音浪数据文件 (ImportUtils)

**功能描述：**
- 从CSV文件导入当天的日音浪数据
- 自动计算当天的总音浪 = 前一天总音浪 + 当天日音浪

**匹配规则：**
- 根据本地数据库中的主播ID前8位进行匹配
- 显示本地数据库中的主播名字（不是CSV文件中的名字）
- 只导入本地数据库中存在的主播，CSV中不在本地数据库的主播会被跳过

**数据来源：**
- 主播列表：从本地数据库 `streamer_data` 表获取
- 最新总音浪：从远程数据库获取前一天的总音浪数据

**计算逻辑：**
```
新的总音浪 = 前一天的总音浪 + 当天的日音浪
```

**使用场景：**
- 每天导入新的日音浪数据
- 首次导入某一天的数据

**文件格式要求：**
- 必须包含列：主播ID、主播名、音浪
- CSV格式，支持UTF-8编码

---

### 2. 更新日音浪功能 (DailySoundUpdateUtils)

**功能描述：**
- 直接修改指定日期的日音浪数据
- 用于数据校准和修正

**匹配规则：**
- 根据ID前8位进行匹配
- 直接更新远程数据库

**数据修改：**
- ✅ 修改：日音浪 (sound_wave)
- ❌ 不修改：总音浪 (total_sound_wave)
- ❌ 不修改：其他字段

**使用场景：**
- 发现某天的日音浪数据有误，需要修正
- 补充或更新已存在日期的日音浪数据
- 不影响总音浪的累计计算

**操作流程：**
1. 选择CSV文件
2. 选择目标日期
3. 预览要更新的数据
4. 确认后直接更新远程数据库
5. 手动点击"同步"按钮将远程数据同步到本地

**文件格式要求：**
- 必须包含列：主播ID、音浪
- CSV格式，支持UTF-8编码

---

### 3. 更新总音浪功能 (TotalSoundUpdateUtils)

**功能描述：**
- 直接修改指定日期的总音浪数据
- 用于修正累计总音浪

**匹配规则：**
- 根据ID前8位进行匹配
- 同时更新远程数据库和本地数据库

**数据修改：**
- ❌ 不修改：日音浪 (sound_wave)
- ✅ 修改：总音浪 (total_sound_wave)
- ❌ 不修改：其他字段

**使用场景：**
- 发现某天的总音浪数据有误，需要修正
- 从主播榜CSV文件导入截至某日的总音浪数据
- 修正累计计算错误

**操作流程：**
1. 选择CSV文件（通常是主播榜格式）
2. 选择目标日期
3. 预览要更新的数据
4. 确认后同时更新远程和本地数据库

**文件格式要求：**
- 必须包含列：主播ID、音浪（总音浪）
- CSV格式，支持UTF-8编码

---

## 功能对比表

| 功能 | 修改日音浪 | 修改总音浪 | 计算总音浪 | 数据来源 | 同步方式 |
|------|-----------|-----------|-----------|---------|---------|
| 导入日音浪数据 | ✅ | ✅ | 自动计算 | 本地数据库主播列表 | 导入后自动 |
| 更新日音浪 | ✅ | ❌ | 不计算 | ID前8位匹配 | 需手动同步 |
| 更新总音浪 | ❌ | ✅ | 不计算 | ID前8位匹配 | 自动同步 |

---

## ID匹配规则

所有三个功能都使用**ID前8位匹配**：

1. **精确匹配优先**：先尝试完整ID匹配
2. **前8位模糊匹配**：如果精确匹配失败，使用ID前8位进行匹配
3. **双向匹配**：
   - CSV的ID前8位 匹配 数据库ID的前8位
   - 数据库ID的前8位 匹配 CSV的ID前8位

**示例：**
```
CSV ID:     MS4wLjABAAAA1234567890abcdef
数据库 ID:  MS4wLjAB
匹配结果：  ✅ 成功（前8位都是 MS4wLjAB）
```

## 注意事项

1. **导入日音浪数据**：
   - 必须先有本地数据库中的主播记录
   - 会自动计算总音浪，确保前一天的数据正确
   - 只导入本地数据库中存在的主播

2. **更新日音浪**：
   - 只修改日音浪，不影响总音浪
   - 适合修正单日数据错误
   - 更新后需要手动同步到本地

3. **更新总音浪**：
   - 只修改总音浪，不影响日音浪
   - 适合修正累计数据错误
   - 自动同步到本地和远程

4. **数据一致性**：
   - 建议按顺序导入数据（从早到晚）
   - 修正数据后，检查后续日期的总音浪是否需要重新计算
   - 定期备份数据库
