# 直播时长排序功能说明

## 功能概述
在设置页面的"排序设置"中新增"直播时长"排序选项，支持按主播的有效直播时长进行升序或降序排序。

## 修改内容

### 1. 数据模型 (ExportSettings.kt)
添加了新的排序字段枚举值：

```kotlin
enum class SortField {
    OVERALL_RANK,           // 按排名
    SOUND_WAVE,            // 按当日音浪
    TOTAL_SOUND_WAVE,      // 按总音浪
    STREAMER_NAME,         // 按姓名
    GRADE_RANK,            // 按等级
    BROADCAST_DURATION     // 按直播时长（新增）
}
```

显示名称：
```kotlin
SortField.BROADCAST_DURATION -> "直播时长"
```

### 2. 数据仓库 (SoundDataRepository.kt)

#### 添加时长解析函数
```kotlin
/**
 * 解析时长字符串为分钟数（用于排序）
 * 支持格式: "2.5小时", "2小时30分钟", "150分钟"等
 */
private fun parseDurationToMinutes(duration: String): Int {
    return (parseDurationToHours(duration) * 60).toInt()
}
```

#### 在两个排序方法中添加时长排序逻辑

**applySorting 方法**：
```kotlin
SortField.BROADCAST_DURATION -> {
    // 按直播时长排序
    if (settings.sortOrder == SortOrder.ASC) {
        rangeFiltered.sortedBy { 
            it.effectiveBroadcastDuration?.let { duration ->
                parseDurationToMinutes(duration)
            } ?: 0
        }
    } else {
        rangeFiltered.sortedByDescending { 
            it.effectiveBroadcastDuration?.let { duration ->
                parseDurationToMinutes(duration)
            } ?: 0
        }
    }
}
```

**applySortingOnly 方法**：
同样的逻辑，用于只应用排序不做筛选的场景。

### 3. 导出工具 (ExportUtils.kt)

#### 添加时长解析函数

## 使用方法

### 在设置页面设置排序
1. 打开应用，点击底部导航栏的"设置"
2. 滚动到"排序设置"部分
3. 点击"排序字段"
4. 选择"直播时长"
5. 选择排序方式（升序/降序）
6. 点击"保存"

### 排序效果
- **升序**：时长从少到多排列（0小时 → 最多小时）
- **降序**：时长从多到少排列（最多小时 → 0小时）
- **未开播主播**：时长为0，会排在最前面（升序）或最后面（降序）

## 时长格式支持

程序支持多种时长格式：
- `"2.5小时"` - 小数形式
- `"2小时30分钟"` - 小时+分钟
- `"150分钟"` - 纯分钟
- `"0小时"` - 未开播

所有格式都会被转换为分钟数进行排序，确保排序准确。

## 应用场景

1. **查看开播时长排行**
   - 降序排列，查看哪些主播开播时间最长
   - 用于考勤统计和工作量评估

2. **查找未开播主播**
   - 升序排列，快速找到未开播或开播时间短的主播
   - 用于督促和管理

3. **导出时长报表**
   - 按时长排序后导出PNG图片
   - 用于月度考勤报告

## 注意事项

1. **时长数据来源**
   - 时长数据需要从CSV文件导入
   - 或者从时长考勤页面导入
   - 如果没有时长数据，该字段为空，排序时视为0

2. **与其他排序的配合**
   - 可以先按性别筛选，再按时长排序
   - 可以设置音浪范围筛选，再按时长排序
   - 排序设置会保存，下次打开应用时自动应用

3. **数据更新**
   - 修改排序设置后，数据会自动刷新
   - 导入新的时长数据后，排序会自动应用

## 技术细节

### 时长转换逻辑
1. 解析时长字符串（支持多种格式）
2. 统一转换为分钟数（整数）
3. 使用分钟数进行排序比较
4. 空值或无效值视为0分钟

### 性能优化
- 使用Kotlin的sortedBy/sortedByDescending进行高效排序
- 时长解析结果会在排序过程中缓存
- 大数据量下排序性能良好
